| BUG-003 | **The pre-push security gate could not tell a scanner FAILURE from a scanner FINDING.** `semgrep … \|\| { echo "found a WARNING+ finding"; exit 1; }` treated every non-zero exit as a finding, but semgrep exits 1 for findings and **≥2 for a fatal error** — and `--quiet` suppressed the reason entirely.
